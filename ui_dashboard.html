Phương thức Xác thực (AuthMech)

Phương thức Cổng Bộ lọc Wireshark & Thứ tự gói Hành động
AuthMech-1 - Web Admin Interface
HTTPS / TLS 1.3
 443/tcp
Cipher: tls.handshake.type == 2 and tcp.port == 443
Mã hóa: http.response.code == 401 or http.authorization
Sort: No.: Server Hello → 401 → Auth → 200
AuthMech-2 - SSH Remote CLI
SSHv2 (RFC 4253)
 22/tcp
Cipher: ssh.message_code == 20 and ip.src == ...
Mã hóa: tcp.port == 22 and ssh
Sort: No.: Banner → KEX 20 → NEWKEYS 21 → Auth
AuthMech-3 - RTSPS Media Stream
RTSP over TLS 1.3
 322/tcp
Cipher: tls.handshake.type == 2 and tcp.port == 322
Mã hóa: rtsp.authchallenge or rtsp.status == 401 or rtsp.authorization
Sort: No.: 401 Challenge → Basic Auth → 200 OK
AuthMech-4 - ONVIF Device Service
HTTPS SOAP (WSS 1.0)
 443/tcp
Cipher: tls.handshake.type == 2 and tcp.port == 443
Mã hóa: http contains "UsernameToken" or "PasswordDigest"
Sort: No.: Server Hello → SOAP POST → 200 OK

Kịch bản nhanh:
1. SQL Injection (SQLi)
CỔNG 443
Vector & Điểm kiểm thử:
Auth Bypass (' OR 1=1--)
Blind Boolean / Time-based
Web SPA, /axis-cgi/login.cgi, Session
2. Cross-Site Scripting (XSS)
CỔNG 443
Vector & Điểm kiểm thử:
<script>alert(1)</script>
SVG onload / Event Handlers
Headers CSP, X-Content-Type, Nosniff
Cơ chế bảo vệ:
Khử khuẩn đầu vào (HTML/JS Sanitization)
Không phản xạ nguyên dạng payload trong DOM
3. CSRF & Token Cấu hình
CỔNG 443
Vector & Điểm kiểm thử:
Origin / Referer Spoofing
Forged Anti-CSRF Token Rejection
VAPIX / REST Config Modification
Bộ lọc Wireshark Display Filter (Web Input Validation) DUT Integrity Enforced

http contains "SELECT" || http contains "<script>" Dò SQLi / XSS
http.request.method == "POST" && tcp.port == 443 Gói cấu hình
