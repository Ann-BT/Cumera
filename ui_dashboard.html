Xác thực Dữ liệu Đầu vào (Input Validation)

QCVN 11:2026/BCA Điều 2.10.1 & Phương pháp đo 3.10.1.3 • IXIT 29-InpVal

User Input Validation
15 Tests
• Type checking: string, integer, IP, MAC, email
• Range checking: port 1-65535, resolutions, schedule 0-23h
• Length checking: password 8-16, username 1-32, name 1-64
• Sanitize input: whitelist XSS, SQLi, Command Injection
• Reject & Log: từ chối dữ liệu sai, ghi Security Audit Log
API Input Validation
7 Tests
• ONVIF (ExtAPI-1): XSD schema, truncated XML, anti-XXE
• REST (ExtAPI-2): JSON schema, malformed JSON syntax
• Parameters check: kiểm tra type, range, length trên API
• Token Gatekeeper: xác thực Token trước khi parse payload
• Xử lý lỗi an toàn: ngắt kết nối an toàn, SOAP Fault / HTTP 4xx
Network Channel Validation
10 Tests
• RTSP/RTP: drop gói tin sai RFC standard
• NTP Anti-Spoofing: từ chối độ lệch thời gian > 5 phút
• DHCP Anti-Rogue: từ chối DHCP server ngoài subnet
• DoT: xác thực DNS qua TLS chống DNS spoofing
• ComMech Channels: SFTP traversal, SMTPS 4KB, SNMPv3, Alarm
Mục tiêu kiểm định: 192.168.99.84 (HTTPS: 443 | RTSP: 554)
